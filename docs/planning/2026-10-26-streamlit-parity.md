Each row was reviewed; a check means the stated behavior has source/test evidence, **not visual acceptance**. This audit does not claim screenshots were reviewed or that every listed test was executed here. Browser verification and suite results must be recorded separately.

v3 key: ✓ covered; ↔ intentionally adapted by the generic contract; ◐ partial (remaining gap stated); ⏸ parked by explicit controller ruling; — unused legacy helper. File references in v3 are relative to `workbench/`: unqualified backend tests are under `tests/`, frontend components/tests under `web/src/` (dataset components unless specified). Descriptive labels and schema-driven controls replace literal metric-specific UI. Dsr is the active experimental dataset; Dgen support is legacy and its masks remain reusable, not evidence for a new Dgen experiment.
